# Einismen arjessa

{{< lead >}}Keskey siihen, mitä voit vaikuttaa. Päästä irti siitä, ettei voi hallita. Valitse seuraava selkeä askel.{{< /lead >}}

{{< hero-image >}}

{{< /section >}}

{{< section class="split" >}}

{{< box class="span-4" >}}

### Tottumukset

Rakenna pieniä tottumuksia, jotka kestävät pidempään kuin suuret lupaukset.

{{< /box >}}

{{< box class="span-4" >}}

### Stressi

Erota se, mihin voit vaikuttaa ja se, mikä täytyy hyväksyä.

{{< /box >}}

{{< box class="span-4" >}}

### Suhteet

Ole selkeä. Pidä sanasi. Vältä turhaa epäselvyyttä.

{{< /box >}}

{{< box class="span-6" >}}

### Vastuu

Taustasi merkitsee, mutta seuraava valinta on silti sinun.

{{< /box >}}

{{< box class="span-6" >}}

### Tasapaino

Sinun ei tarvitse hallita kaikkea. Sinun täytyy tietää, mikä on voiman arvoista.

{{< /box >}}
