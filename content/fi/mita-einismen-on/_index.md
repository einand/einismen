# Mikä Einismen on?

{{< lead >}}Einismen lähtee siitä, ettei maailma anna valmiita vastauksia. Ihminen tarvitsee ajatella itse, valita suunnan ja seistä valintojensa takana.{{< /lead >}}

{{< hero-image >}}

Se on sekä elämänasenne että menetelmä. Se yrittää yhdistää realismin vastuuseen, [vapauden](../pelare/vapaus) seurauksiin ja [muutoksen](../pelare/muutos) harkintaan.

{{< /section >}}

{{< section class="split" >}}

{{< box class="span-6" >}}

<span class="mini-label">Ei tätä</span>

- Ei sokeaa uskoa.
- Ei valmiita vastauksia kaikkeen.
- Ei tyhjää perinnettä.
- Ei muutosta muutoksen itsensä vuoksi.

{{< /box >}}

{{< box class="span-6" >}}

<span class="mini-label">Vaan tämä</span>

- Selkeä tapa ajatella.
- Tiukka tapa elää.
- Menetelmä parempiin päätöksiin.
- Tuki jatkuvaan parantamiseen.

{{< /box >}}
