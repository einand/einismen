# Työ ja johtajuus

{{< lead >}}Toiminta menee ennen pramia. Päätösten tulee olla selkeitä, testattavia ja mahdollisia parantaa.{{< /lead >}}

{{< hero-image >}}

{{< /section >}}

{{< section class="split" >}}

{{< box class="span-6" >}}

### Pragmaattisuus

Menetelmät eivät ole pyhiä. Jos jokin toimii paremmin, sen tulisi saada korvata vanha.

{{< /box >}}

{{< box class="span-6" >}}

### Iterointi

Pienet säädöt usein voittavat suuret uudelleenalut.

{{< /box >}}

{{< box class="span-6" >}}

### Johtajuus

Johtajan tulee olla selkeä, asiallinen ja pystyä muuttamaan kun pohja paranee.

{{< /box >}}

{{< box class="span-6" >}}

### Yhteistyö

Itsenäisyys on hyvä. Oikea yhteistyö on usein parempi.
