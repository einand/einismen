# Etik och konflikter

{{< lead >}}Einismen söker inte perfekta regler. Den söker tydlighet, ansvar och fungerande gränser.{{< /lead >}}

### Etik

Det viktiga är konsekvens, ansvar och verklig effekt.

{{< /box >}}

{{< box class="span-4" >}}

### Moral

Människan måste tänka själv och bära sina bedömningar.

{{< /box >}}

{{< box class="span-4" >}}

### Kommunikation

Var tydlig och saklig, även när andra inte är det.

{{< /box >}}

### Konflikter

Välj inte konflikt för sin egen skull. Undvik inte heller nödvändiga gränser.

{{< /box >}}

### Manipulation

Se den tidigt. Håll dig lugn. Ge inte upp klarheten.
