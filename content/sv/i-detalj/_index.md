        <section class="section prose">
          <h2>Översikt</h2>
          <p>`I detalj` är uppdelad i undersidor som följer samma struktur som de viktigaste delarna i filosofin. Här kan du gå från en översiktlig bild till mer fokuserade genomgångar av <a href="om-filosofin">ursprung</a>, <a href="varderingar">värderingar</a>, <a href="etik-och-principer">etik</a>, <a href="praktisk-tillampning">tillämpning</a>, <a href="resonemang-och-logik">logik</a>, <a href="exempel">exempel</a> och <a href="kritik-och-invandningar">kritik</a>.</p>
          <p>Om du i stället vill läsa mer sammanhängande och mer deklarativa tekstit ska du gå till <a href="../texter">Texter</a>. `I detalj` är till för att orientera, jämföra och förstå varje område för sig.</p>
        </section>
