# Förbättringens gränser

{{< lead >}}Förbättring är värdefull när den tjänar ett verkligt ändamål. Den blir skadlig när människan reduceras till något som alltid ska optimeras.{{< /lead >}}

{{< hero-image >}}

## Funktion och människovärde

Uppmaningen att utvecklas kan bli ett krav på att allt ska bli snabbare och mer produktivt. Då glöms frågan om vem som betalar kostnaden.

## Vila och bevarande

Människors värde beror inte på prestation. Ett effektivare arbetssätt kan samtidigt skada hälsa, tillit eller värdighet.

## Vad bör förändras?

Vila kan vara ett villkor för omdöme. Bevarande kan skydda kunskap, gemenskap och stabilitet som en förändring skulle förstöra.

## Ett mått på förbättring

Fråga vilket problem förändringen löser och vem som gynnas. Ibland innebär förbättring att göra mindre, bevara det som fungerar eller avstå från en alltför kostsam lösning.
