# Invändningar mot Einismen

{{< lead >}}Einismen betonar klarhet, ansvar och funktion. Därför behöver den prövas mot risken att värdena förenklar människor och deras villkor.{{< /lead >}}

{{< hero-image >}}

## Rationalismens gräns

Krav på styrka kan bli hårda mot människor med sjukdom, utsatthet eller få val. Ansvar behöver skiljas från skuldbeläggning utan handlingsutrymme.

## Individualism och beroende

Känslor bär information om behov och skada. De avgör inte ensamma vad som är sant, men bör inte heller avfärdas som störningar.

## Funktion för vem?

Frihet kan skymma människors beroende av varandra och gemensamma institutioner. Samtidigt kan gemenskap kräva lydnad. Båda sidor behöver hållas synliga.

## Frågor som förblir öppna

När funktion används som mått måste vi fråga: funktion för vem och till vilket pris? Filosofins trovärdighet beror på att den erkänner öppna frågor, lyssnar på kritik och ändrar sig när skälen kräver det.
