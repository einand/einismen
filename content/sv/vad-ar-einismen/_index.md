# Vad är Einismen?

{{< lead >}}Einismen utgår från att världen inte ger färdiga svar. Människan behöver tänka själv, välja riktning och stå för sina val.{{< /lead >}}

{{< hero-image >}}

Det är både en livshållning och en metod. Den försöker förena realism med ansvar, [frihet](../pelare/frihet) med konsekvens och [förändring](../pelare/forandring) med eftertanke.

{{< /section >}}

{{< section class="split" >}}

{{< box class="span-6" >}}

<span class="mini-label">Inte detta</span>

- Inte blind tro.
- Inte färdiga svar på allt.
- Inte tom tradition.
- Inte förändring för förändringens skull.

{{< /box >}}

{{< box class="span-6" >}}

<span class="mini-label">Snarare detta</span>

- Ett klart sätt att tänka.
- Ett stramt sätt att leva.
- En metod för bättre beslut.
- Ett stöd för ständig förbättring.

{{< /box >}}
