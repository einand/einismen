# Arbete och ledarskap

{{< lead >}}Funktion går före prestige. Beslut ska vara tydliga, prövbara och möjliga att förbättra.{{< /lead >}}

### Pragmatik

Metoder är inte heliga. Om något fungerar bättre ska det få ersätta det gamla.

{{< /box >}}

{{< box class="span-6" >}}

### Iteration

Små justeringar slår ofta stora omstarter.

{{< /box >}}

{{< box class="span-6" >}}

### Ledarskap

En ledare ska vara tydlig, saklig och kunna ändra sig när underlaget blir bättre.

{{< /box >}}

{{< box class="span-6" >}}

### Samarbete

Självständighet är bra. Rätt samarbete är ofta bättre.
