# Work and leadership

{{< lead >}}Function comes before prestige. Decisions should be clear, testable and possible to improve.{{< /lead >}}

{{< hero-image >}}

{{< /section >}}

{{< box class="span-6" >}}

### Pragmatism

Methods are not sacred. If something works better, it should replace the old.

{{< /box >}}

{{< box class="span-6" >}}

### Iteration

Small adjustments often beat major restarts.

{{< /box >}}

{{< box class="span-6" >}}

### Leadership

A leader should be clear, sober and able to change when the evidence improves.

{{< /box >}}

{{< box class="span-6" >}}

### Cooperation

Independence is valuable. The right cooperation is often better.
