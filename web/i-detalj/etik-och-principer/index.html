Etik och principer

Einismen föreslår inte oändliga regelverk, men den pekar tydligt ut hur människan bör handla om hon vill leva med integritet.

Människan bör agera så att hennes ord kan bäras av hennes handlingar. Hon bör vara tydlig, ansvarstagande och öppen för att ompröva sig när bättre förståelse visar sig. Hon bör inte välja det bekväma framför det sanna bara för att undvika friktion.

Einismen ger riktlinjer snarare än stela lagar: välj funktion utan att överge etik, skydda din frihet utan att förakta andras, och sätt gränser mot sådant som bryter ned klarhet, tillit och riktning.

Förhållningssättet till andra bör vara sakligt, respektfullt och tydligt. Det betyder inte eftergivenhet, men det betyder att gränser ska sättas med omdöme snarare än affekt.
