Bygg inre styrka

När yttre ordning inte kan garanteras blir inre stadga desto viktigare. Därför gör Einismen dygderna praktiska.

Inre styrka handlar inte om hårdhet för sin egen skull. Den handlar om att kunna stå kvar i klarhet när omständigheterna skiftar. Visdom, mod, självdisciplin, integritet och reflektion återkommer därför som centrala redskap.

Visdom gör det möjligt att skilja mellan vad som kan påverkas och vad som måste accepteras. Mod gör att människan kan handla trots rädsla. Självdisciplin gör att hon kan hålla riktning över tid. Integritet gör att hon inte glider isär mellan ord och handling. Reflektion gör att hon kan lära i stället för att bara reagera.

Den här pelaren gör Einismen mindre beroende av yttre tur. Den säger inte att människan kan kontrollera allt, men att hon kan bygga en hållning som gör henne mindre lätt att splittra.
